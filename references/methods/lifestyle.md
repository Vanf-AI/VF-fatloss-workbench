# 生活化减脂方法（lifestyle）

目标是减脂而非短期快速减重；以三个月作为一个可执行周期。不计算基础代谢，直接按体重和每周运动时长确定碳水、蛋白质、脂肪的日目标。

## 每日三大营养素目标

每日克数 = `体重（kg）× 对应系数`。运动时长以一周合计计。

| 每周运动 | 男性：碳水 / 蛋白质 / 脂肪（g/kg） | 女性：碳水 / 蛋白质 / 脂肪（g/kg） |
| --- | --- | --- |
| 2–3 小时 | 2.2 / 1.4 / 0.8 | 2.0 / 1.4 / 1.0 |
| 4–5 小时 | 2.5 / 1.6 / 0.9 | 2.2 / 1.6 / 1.1 |
| 6–7 小时 | 3.0 / 1.7 / 1.0 | 2.5 / 1.7 / 1.1 |
| 8–9 小时 | 3.5 / 1.8 / 1.0 | 3.0 / 1.8 / 1.2 |

原视频没有给出少于 2 小时或多于 9 小时的系数，不应擅自外推。计算时按 `exerciseHours` 落入档位：`<4`→第1档，`<6`→第2档，`<8`→第3档，否则第4档。

## 计算口径

### 不计入
蔬菜与蓝莓不计入热量与碳蛋脂目标。蔬菜建议品种：西兰花、菠菜、生菜、番茄、黄瓜、彩椒、菌菇、大白菜、胡萝卜、西葫芦、冬瓜、芹菜、豆角、油麦菜、娃娃菜、金针菇；蓝莓示例每次约 100g。

### 计入
主食、肉蛋、蛋白粉、牛奶、水果（蓝莓除外）、坚果、烹调油及其他固定摄入；有包装标签时以标签为准，无标签用 [food-table.md](food-table.md) 兜底口径。

### 简化计算
营养值统一以 [food-table.md](food-table.md) 与前端 `fooddb.json` 为准，关键摘录：
- 燕麦每 100g：碳水 60g、蛋白 13g、脂肪 7g。
- 全蛋每个：碳水 0.7g、蛋白 6.5g、脂肪 4.5g（按「个」录入）。
- 米面按生重记录；肉类按生重。
- 薯类（每 100g）：红薯/紫薯碳 22、土豆碳 17、贝贝南瓜碳 8；普通南瓜不计入这组。
- 白肉可选：鸡胸、去皮鸡腿肉、鸭腿（去皮更优）、巴沙鱼、青花鱼、虾仁；红肉可选瘦牛肉。

## 三餐结构

| 餐次 | 主食 | 蛋白质 | 其他 |
| --- | --- | --- | --- |
| 早餐 | 燕麦 | 全蛋 | 蓝莓、南瓜子 |
| 午餐 | 生米 | 白肉或虾仁 | 蔬菜、烹调油 |
| 晚餐 | 薯类 | 瘦牛肉 | 蔬菜、烹调油、混合坚果 |

## 调整规则

1. 连续执行 7–10 天，记录体重趋势和对比照片。
2. 下降过快时适当提高碳水；下降过慢时适当降低碳水。
3. 每次只做小幅调整，观察后再决定下一步。
4. 体重来到新的稳定水平（阶段降 ≥3%）时，用新体重重新计算碳蛋脂目标。

## 烹调与盐
高烟点油用于炒菜，橄榄油用于凉拌/淋油；运动人群每日总盐约 6–8g，酱油等调味料计入（1g 钠 ≈ 2.5g 盐）。
