# 执行流程

本文件定义从档案到周餐单的生成步骤。查阅前先确认已完成 [screening.md](screening.md) 与 [methods/index.md](methods/index.md) 的方法选择。

## 1. 采集（已在工作流第 1 步）
档案：性别、体重、每周运动时长与次数、起始日。固定摄入：蛋白粉、牛奶及品牌标签。

## 2. 算目标
按所选方法的口径（见 `methods/`）：
- `lifestyle`：体重 × 系数表 → `goal`。
- `carb-cycle`：当前阶段系数 × 体重 → 阶段 `goal`；高碳日单独标注。
- `recomposition`：`method.startPoint` × 体重 → 初始 `goal`，后续按波形调整。

## 3. 选食材 + 口味自定义
从 [food-table.md](food-table.md) 让用户勾选蛋白 / 主食 / 蔬菜；记录南瓜籽、混合坚果是否计入。蓝莓、蔬菜默认不计入目标。
**口味自定义（生成期，必做）**：排餐单前主动征询——忌口/不吃的食材、想多吃的、替换偏好、份量偏好、某天特殊安排（外食/训练日/聚餐）。按回答调整七日食材与份量；替换遵循等量换算 + 用油补偿口径，不改变每日碳蛋脂目标。

## 4. 生成周餐单
- 七日，每天四餐（早餐 / 午餐 / 晚餐 / 加餐）。
- 主食口径：燕麦只在早餐；午餐默认大米、可被薯类替换；晚餐默认薯类轮换（红薯 / 紫薯 / 土豆 / 贝贝南瓜）。
- 备餐（午餐批做）：`lunchBatchDays` 1–3，>1 时连续几天午餐同一道菜一次做好分装，批内每天仍是自己一份。
- 加餐：有蛋白粉时训练后安排蛋白粉（及可选牛奶），否则下午。
- 每餐食材按 `foodLibrary` 与固定摄入填入份量。

## 5. 配平与采购
- 全周餐后做主动配平：实际碳蛋脂合计贴近 `goal`（±2% 视为达标）。
- 汇总七日全部食材 → 采购清单 `shopping[]`（名称 + 总量 + 勾选状态）。

## 6. 确认闸
展示周餐单与采购清单，用户确认后再写入 `weeklyPlan.confirmed = true`。未确认不得进入记录阶段。

## 7. 记录与复盘
见 [review.md](review.md)。每 7 天做一次复盘，写 `reviews[]` 与 `nextGoal`；归档已完成周到 `history`。
