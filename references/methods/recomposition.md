# 增肌减脂并行方法（recomposition）

以训练表现、主观状态和渐进调整为中心，用于希望同时改善力量表现、肌肉表现和体脂的人群；不与固定日期的碳水循环表混用。

## 核心框架
- 训练强度为增肌关键观察项：重量、容量、休息、次数、组数、力量变化。
- 短期热量缺口、长期状态稳定为减脂共同观察项；参考缺口每日 200–300 kcal。
- 不以强迫进食或极端挨饿为手段；训练状态、精神状态、睡眠和食欲共同决定是否调整。

## 起始宏量范围（写入 `method.ranges` 与 `method.startPoint`）

| 营养素 | 参考范围（g/kg） | 调整依据 |
| --- | --- | --- |
| 脂肪 | 0.6–0.8 | 保持脂肪来源整体平衡 |
| 蛋白质 | 1.2–2.0 | 以消化耐受和训练需要调整 |
| 碳水 | 2.5–3.5 | 易胖体型从低端开始，易瘦体型从高端开始 |

- `startPoint` 为初始目标（g/kg），必须落在 `ranges` 内。
- 蛋白质优先选可稳定消化的优质蛋白，红白肉交替。
- 进食量或蛋白质调整跟随实际消化耐受；不把"吃得越多越好"作为规则。

## 波形调整（stateSignals）
1. 以当前碳水水平连续观察约 10 天至半个月。
2. 对碳水有明显渴望且训练 / 精神状态良好时，小幅提高碳水。
3. 胃口下降、对食物渴望降低或感觉吃撑时，降低碳水（示例从 3.5 回到 3–3.5 g/kg）。
4. 碳水上调时蛋白可略降；下调时蛋白可略升；脂肪维持在适用范围内。
5. 目标：避免大幅跳变，维持轻微饥饿但不影响训练、精神和睡眠的状态。

## 有氧与恢复
- 有氧示例：每周 3–4 次，每次 30–40 分钟；时间基本不变时逐步提高强度，前提是不影响力量训练状态。
- 状态差时优先回看睡眠、有氧量和饮食，而非机械加大缺口。
- 记录体重和体型照片辅助判断变化方向。

## 状态信号
有训练欲望、专注力较强、精神充足、愿意社交视为良好状态参考。持续疲劳、训练状态下降、睡眠变差或食欲明显异常时，先排查训练 / 有氧 / 饮食 / 睡眠组合，而不是继续加码。
